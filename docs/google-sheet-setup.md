# 설문 응답 저장·통계 연결 방법 (구글 시트)

## 연결 (처음 한 번, 약 5분)
1. 구글 드라이브에서 새 스프레드시트 생성 (예: `ADHD 테스트 설문 응답`)
2. 상단 메뉴 **확장 프로그램 → Apps Script**
3. 기본 코드를 모두 지우고 `docs/apps-script.gs` 내용 붙여넣기 → 저장(💾)
4. 위쪽 함수 선택 칸에서 **setup** 선택 → **실행** → 구글 계정 권한 허용
   (경고 화면에서 고급 → 이동 클릭). 시트에 `응답`, `통계` 탭이 생김
5. 오른쪽 위 **배포 → 새 배포**
   - 유형 선택(톱니바퀴): **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포** → 표시되는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`) 복사
7. `config.js`의 `window.SURVEY_ENDPOINT = ""` 따옴표 안에 URL 붙여넣기 후 커밋

## 결과 확인
- `통계` 탭: 문항별 응답 수·비율·평균이 수식으로 자동 갱신됨 (발표자료용)
- `응답` 탭: 응답 원본 전체 (주관식 Q4 포함)
- 시트는 만든 사람과 공유받은 사람만 볼 수 있음. 팀원에게는 시트 공유로 열람 권한 부여
- 웹페이지의 실시간 통계에는 Q1~Q3 객관식 집계만 공개되고, 주관식은 공개되지 않음

## 주의
- '모든 사용자' 권한은 웹 앱 주소로 응답 제출·집계 조회만 허용하는 것이며, 시트 자체는 공개되지 않음
- 스크립트를 수정한 경우 **배포 → 배포 관리 → 수정(연필) → 새 버전**으로 다시 배포해야 반영됨
